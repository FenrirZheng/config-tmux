* Summary

tmuxlib is a one-file library crate (~630 lines, no submodules), and that file is the shared API every other binary in the workspace links against — its own doc comment calls the option constants "the whole cross-tool API surface". It defines the =@claude_*= pane-option name constants and the State enum (NeedsInput / Idle / Busy / Unknown) with parsing, glyph, and priority-ordering logic; wraps every tmux invocation through =tmux()= / =tmux_ok()= / =tmux_batch()= (with a =CC_TMUX_SOCKET= test seam); builds the pane inventory (=Pane= + =list_claude_panes()=) by parsing one tab-separated =list-panes -F= format string; and centralizes the two safety-critical text-hygiene functions, =sanitize_format()= and =message_literal()=. All ten other crates depend on this file via =tmuxlib = { workspace = true }= — changing an option name, a State transition, or the sanitize rule here changes behavior everywhere at once. It also owns the pane-title fallback heuristic (=title_state=) so panes started before the hooks existed still report a usable state.

* Crux

State resolution: stamped option first, title heuristic as the graceful fallback:

#+begin_src rust :file tmuxlib/src/lib.rs :lines 282-296
    pub fn state(&self) -> State {
        let stamped = State::parse(&self.state_raw);
        if stamped != State::Unknown {
            return stamped;
        }
        title_state(&self.title)
    }

    /// Whether this looks like a Claude Code pane at all.
    pub fn is_claude(&self) -> bool {
        if !self.state_raw.is_empty() || !self.session_id.is_empty() {
            return true;
        }
        title_state(&self.title) != State::Unknown
    }
#+end_src

#+begin_src rust :file tmuxlib/src/lib.rs :lines 386-392
pub fn sanitize_format(s: &str) -> String {
    s.chars()
        .filter(|c| !matches!(c, '#' | '{' | '}' | '%' | ';' | '\n' | '\r' | '\t'))
        .collect::<String>()
        .trim()
        .to_string()
}
