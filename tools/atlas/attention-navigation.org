* Summary

This subsystem is the "which pane needs me right now" layer, split across two binaries that share one ranking philosophy: needs-input always outranks idle, which always outranks busy/unknown. cc-attend is the two-key version (=prefix N= to jump, =prefix B= to bounce back) — it computes a single best target with =pick_target=, marks the pane you are leaving with tmux's own =select-pane -m= so =back= needs no bookkeeping of its own, then reports what it landed on via a sanitized status message. cc-fleet is the browse-everything version: one row per Claude pane (state glyph, age, target, cwd, task, last activity), sorted by the identical state-priority-then-age comparator, handed to fzf in a popup so a human picks manually instead of trusting the top pick. Both read pane state exclusively through =tmuxlib::Pane= (title-heuristic fallback included), and both keep their core logic pure over =&[Pane]= so the ranking is unit-tested without a live tmux server. Two tests pin the ordering: =attention_sorts_before_idle_before_busy_before_unknown= (cc-fleet/src/main.rs, hard-asserts the sorted row order) and =state_priority_orders_attention_first= (tmuxlib/src/lib.rs) — any change to =State::priority()= reddens both before it ships.

* Crux

The shared priority scale both pickers sort by:

#+begin_src rust :file tmuxlib/src/lib.rs :lines 80-88
/// Attention ranking: lower sorts first in every picker in this workspace.
pub fn priority(self) -> u8 {
    match self {
        State::NeedsInput => 0,
        State::Idle => 1,
        State::Busy => 2,
        State::Unknown => 3,
    }
}
#+end_src

=prefix N='s single-target selection: oldest blocked wins, else newest live idle:

#+begin_src rust :file cc-attend/src/main.rs :lines 76-89
fn pick_target<'a>(panes: &'a [Pane], now: u64, origin: &str) -> Option<&'a Pane> {
    let live = || panes.iter().filter(|p| p.id != origin || origin.is_empty());

    let blocked = live()
        .filter(|p| p.state() == State::NeedsInput)
        .min_by_key(|p| (p.since.is_none(), p.since.unwrap_or(0)));
    if blocked.is_some() {
        return blocked;
    }

    live()
        .filter(|p| p.state() == State::Idle && !is_stale_idle(p, now))
        .max_by_key(|p| (p.since.is_some(), p.since.unwrap_or(0)))
}
#+end_src

cc-fleet's full-list ordering — same scale, longest-wait-first tiebreak:

#+begin_src rust :file cc-fleet/src/main.rs :lines 93-105
fn sorted(panes: &[t::Pane], now: u64) -> Vec<&t::Pane> {
    let mut v: Vec<&t::Pane> = panes.iter().collect();
    v.sort_by(|a, b| {
        a.state()
            .priority()
            .cmp(&b.state().priority())
            .then_with(|| {
                b.age_secs(now)
                    .unwrap_or(0)
                    .cmp(&a.age_secs(now).unwrap_or(0))
            })
            .then_with(|| a.id.cmp(&b.id))
    });
    v
}
#+end_src
