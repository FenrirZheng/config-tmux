* Summary

cc-beacon is a single Rust binary invoked once per Claude Code hook event (SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Notification, Stop, SessionEnd) and per Antigravity CLI (=agy=) hook event (=cc-beacon agy session-start|pre-invocation|ask-question|post-tool|stop=, wired in =~/.gemini/config/hooks.json=). Each event handler reads the hook's JSON payload off stdin, derives a lifecycle state (busy / idle / needs-input) and sometimes a short activity string, and writes them onto the calling pane's tmux options in one batched tmux invocation via tmuxlib. For =agy= hooks it also stamps =@claude_agent=agy= and always emits valid JSON on stdout (={}= or ={"decision":"allow"}=) even outside tmux. It also maintains a per-pane ticker log under =/tmp/claude-progress/= and rings the pane's tty BEL on Notification / =ask_question= / error-stop only when the human is not already looking at that pane. (Status bar installation, =@claude_tab_glyph= / =@claude_tab_glyph_mono=, the =status-right= fleet roster, and existing-window =pane-border-status= initialization moved to the C++20 =tools/tmux-bar= binary on 2026-11-19.) It is the only writer of the =@claude_state= family of pane options that every other crate reads; it deliberately never touches pane titles, which belong to =talk ping=. Two invariants run through the binary: every code path exits 0 (a hook must never block the agent), and any text derived from tool arguments passes =sanitize_format= before being stamped into a tmux format context.

* Crux

The whole binary is one event dispatch:

#+begin_src rust :file cc-beacon/src/main.rs :lines 46-56
    match event.as_str() {
        "session-start" => session_start(&pane, &payload),
        "prompt" => prompt(&pane, &payload),
        "activity" => activity(&pane, &payload),
        "tool-done" => tool_done(&pane, &payload),
        "attn" => attn(&pane),
        "idle" => idle(&pane),
        "clear" => clear(&pane),
        _ => {}

#+end_src

Every state write is one batched tmux call — state, timestamp, optional activity, refresh:

#+begin_src rust :file cc-beacon/src/main.rs :lines 171-181
fn stamp_with(pane: &str, state: t::State, set_activity: Option<&str>) {
    let mut commands = vec![
        set_pane(pane, t::OPT_STATE, state.as_str()),
        set_pane(pane, t::OPT_SINCE, &t::now_epoch().to_string()),
    ];
    if let Some(activity) = set_activity {
        commands.push(set_pane(pane, t::OPT_ACTIVITY, activity));
    }
    commands.push(vec!["refresh-client".to_string(), "-S".to_string()]);
    t::tmux_batch(&commands);
}
#+end_src

The attention path only rings the bell when the pane is off-screen:

#+begin_src rust :file cc-beacon/src/main.rs :lines 122-127
fn attn(pane: &str) {
    stamp(pane, t::State::NeedsInput);
    if !is_on_screen(pane) {
        ring_bell(pane);
    }
}
#+end_src
