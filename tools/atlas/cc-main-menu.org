* Summary

=cc-main-menu= is the command palette on =prefix m=: a C++20 + FTXUI popup listing every tmux command (from =list-commands -F=) and every key bound with =-N "note"= (from =list-keys -N -T <table>=), fuzzy-filtered as you type, with each command's bound keys shown as badges joined back from plain =list-keys= text. It is the workspace's third non-Rust tool and the only one built with *Meson* (FTXUI comes in through Meson's cmake module; =scripts/build.sh=), and unlike every other binding here its key is installed by its own entry script, =cc-main-menu.tmux=, which =claude.conf= runs. The flow has three hops, and the order is the design: the key binds =run-shell=, because =display-popup= does not expand =#{…}= formats; =scripts/launch.sh= opens the popup with the caller's client/session/window/pane as plain argv; the binary writes the chosen tmux argv NUL-delimited to a temp file and exits 0, and only after =display-popup= has returned (it blocks until the popup closes) does =launch.sh= run =tmux "${argv[@]}"= — so =copy-mode=, =choose-tree=, =command-prompt= and nested popups get a free client, and a failure surfaces as a literal =display-message -l=. A command row runs with =-t=/=-c=/=-s= flags derived from its usage string, so it acts on the pane the menu was opened from rather than on the marked inbox pane tmux would pick as a source; a command that names a source and destination of one kind (=swap-window=, =join-pane=…) opens the argument bar at =-t = on Enter instead of running as a silent no-op, and one with a required argument (=rename-window new-name=) opens it at =NAME = rather than failing with "too few arguments"; a noted-key row is replayed as a keystroke (=send-keys -K=), so its formats expand exactly as when the key is pressed. =cc-main-menu rows [QUERY]= and =resolve LINE= are the headless seams, and =scripts/verify.sh= pins the parsers, badge join, ranking, flag derivation and the whole popup-then-run path with 59 assertions on a nested pair of throwaway servers.

* Crux

The target flag is read off the usage string, not a table of commands. The one exception is measured: =new-window -t @id= means "create at that index" and fails, so it gets =$session:= instead:

#+begin_src cpp :file cc-main-menu/src/tmux_client.cpp :lines 571-588
  if (!has_flag(user_args, 't')) {
    std::string value;
    if (usage_has(u, "-t target-pane"))
      value = ctx.pane;
    else if (usage_has(u, "-t target-window"))
      // new-window -t @id means "create AT that index" and fails with
      // "index N in use"; `$session:` picks the next free index like prefix c.
      value = cmd.name == "new-window" ? (ctx.session.empty() ? "" : ctx.session + ":")
                                       : ctx.window;
    else if (usage_has(u, "-t target-session"))
      value = ctx.session;
    else if (usage_has(u, "-t target-client"))
      value = ctx.client;
    if (!value.empty()) {
      out.emplace_back("-t");
      out.push_back(std::move(value));
    }
  }
#+end_src

A noted key is not re-parsed into a command; it is pressed again on the origin client, through the prefix when it lives in the prefix table:

#+begin_src cpp :file cc-main-menu/src/tmux_client.cpp :lines 633-647
  // A lone ";" argument separates commands on the tmux command line.
  const std::string key = action.key == ";" ? "\\;" : action.key;
  std::vector<std::string> argv;
  if (action.table == "prefix") {
    if (catalog.prefix.empty() || catalog.prefix == "None") {
      error = "the prefix option is None; cannot replay a prefix key";
      return std::nullopt;
    }
    argv = {"send-keys", "-K", "-c", ctx.client, catalog.prefix, key};
  } else if (action.table == "root") {
    argv = {"send-keys", "-K", "-c", ctx.client, key};
  } else {
    argv = {"switch-client", "-c", ctx.client, "-T", action.table, ";",
            "send-keys",     "-K", "-c",       ctx.client, key};
  }
#+end_src

Popup first, command second — the binary never runs the choice itself:

#+begin_src bash :file cc-main-menu/scripts/launch.sh :lines 29-40
tmux display-popup -E -c "$client" -t "$pane" -w "$width" -h "$height" \
  -T ' main menu ' "$cmd" || true

[[ -s $out ]] || exit 0            # cancelled
mapfile -d '' -t argv < "$out"
(( ${#argv[@]} )) || exit 0

if ! tmux "${argv[@]}" 2>"$errf"; then
  msg=$(tr '\n' ' ' < "$errf" | head -c 300)
  tmux display-message -c "$client" -l "cc-main-menu: ${argv[0]}: ${msg:-failed}"
fi
exit 0
#+end_src
