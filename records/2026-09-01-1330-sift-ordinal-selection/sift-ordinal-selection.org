* Destination

=prefix /='s result list can be driven by number: Left =Alt-<digit>= opens ordinal
mode with that digit, further digits extend it, the selection follows live, and
=Enter= jumps — with the regex input, the arrow keys, and ADR-0005's hand-back of the
jump to tmux all unchanged. Reached when the behaviour is built, asserted by the two
verification suites, and documented where the other =sift= behaviour is documented.

* Decisions so far

* Not yet specified

- Whether the ordinal column's width should keep tracking the current /N/ (and so
  jitter as the pattern changes) or be pinned the way =draw()= pins the line-number
  column from the capture size. Only using the feature will say.
- Whether ordinal mode wants any indicator beyond the =goto>= prompt once it is in
  daily use — the popup header has room, but inventing one before the feature has been
  lived with is guessing.

* Out of scope

- =seek= and =prefix Space= — untouched; ADR-0001 still stands for plain search.
- The =Sift= entry missing from [[file:../../CONTEXT.org][CONTEXT.org]] (which defines =Seek=). A real gap, but it
  predates this effort and does not lie toward this destination.
- Any change to how the jump itself is performed. ADR-0005's hand-back to tmux's
  =search-backward= is what keeps highlighting, ~n~ / ~N~ and seek's grab keys working,
  and this effort does not touch it.
- Hint-label selection, screen-local or otherwise — considered and rejected in
  ADR-0007, not deferred.

*** Question

Every probe taken during the grill synthesised the keystroke with =tmux send-keys M-1=,
never a physical key, so the =keyboard → alacritty → tmux= leg of the path is
=[未驗証]=. =~/.config/alacritty/alacritty.toml= does not set =alt_send_esc=, so the
claim currently rests on alacritty's documented default rather than on a measurement.

This gates everything after it: if a physical Left =Alt-1= does not arrive as
=0x1b 0x31=, ADR-0007's entry channel is wrong and the decision has to be reopened
rather than implemented around.

HITL — it needs a human to press the key. The cheapest observable that does not
require touching the code: open =prefix /= on the real server, type a letter so the
pattern is non-empty, press Left =Alt-1=, and report whether the popup stayed open
(=ESC= arrived paired, correct) or closed (=ESC= arrived bare, channel unusable) —
and then whether a following letter shows the digit leaked into the pattern.

Record the observation in the Resolution either way, including the negative form.
