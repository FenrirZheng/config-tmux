#+TITLE: tmux status bar polish — flat blocks + Nerd Font state glyphs
#+DATE: 2026-10-23 (Asia/Taipei)

* Why

User, 2026-10-23: the self-customized bottom bar 「美感不足, icon沒有藝術氣息」.
Diagnosis on the live server (tmux 3.5a, catppuccin mocha v2.3.0, gitmux,
Alacritty + DejaVuSansM Nerd Font, non-Mono):

1. =✋= (U+270B) is not in DejaVuSansM Nerd Font —
   =fc-match 'DejaVuSansM Nerd Font:charset=270b'= returned VL Gothic, so the
   red alert glyph in tabs, roster and pane border was drawn by a CJK fallback.
2. Module pills were rounded-left / flat-right: catppuccin's default
   =@catppuccin_status_right_separator= is a bare space.
3. Tabs were =basic= rectangles while modules were rounded capsules.
4. Each Claude tab carried two glyphs: Claude Code's =✳= title prefix plus
   cc-beacon's state glyph appended after the tab.
5. gitmux symbols (=↑· ↓· ● ✖ ✚ … ⚑ ✔=) were a third visual family.

Second round, same day: a screenshot critique the user pasted after the first
pass found five more defects, all confirmed on the server and fixed:

6. The CURRENT tab stayed square. catppuccin fills
   =@catppuccin_window_current_*_separator= with =set -o= (only if unset), and
   the running server still held the =basic= values.
7. The session pill touched tab 0 (read as "00"), and =status-left-length= 10
   cut it before its closing cap.
8. A long tab title pushed the row into the right-hand modules (=>= overflow).
9. Four saturated foregrounds inside the gitmux pill, and gitmux's
   =clear: "#[none]"= reset the background mid-pill.
10. The fleet roster repeated a bell per blocked window — the tabs already
    carry those bells.

* User picks (AskUserQuestion, 2026-10-23)

- Direction: 膠囊統一 — stay on catppuccin mocha (theme pick of
  [[file:../2026-08-23-2241-tmux-ui-clarity/tmux-ui-clarity.org]] stands).
- Glyph scope: 整套一起換 — bar, pane border, cc-fleet, cc-attend, cheat sheet,
  docs, atlas share one vocabulary.
- Bar background: try both live (see below).
- Third round: the rounded capsules went live and the user rejected them —
  「膠囊形狀很醜」. Picked 方塊（平切） over minimal text-only, slanted and
  underline. Glyphs, colors, the 20-cell title cap and the single count badge

- =~/.gitmux.conf= (untracked, outside this repo). Symbols: ahead  U+F062,

* Background A/B

=bash ~/.tmux/records/2026-10-23-tmux-bar-polish/try-background.sh none= (or
=default=) rewrites the one option line, unsets =@claude_bar_base_sr=, reloads.
Committed value: =default= (opaque mantle) until the user picks. With =none=
the module end blocks are drawn in the module's own color, so they keep their
shape on a transparent bar.

* Round four: palette and tab information (2026-10-23)

Shapes stay flat blocks. A brief from the user named the remaining defects as
colour and information, not geometry, all confirmed on the live server:

1. Six hues in one row: green session, purple active tab, grey inactive
   tabs, teal git icon cell, pink folder icon cell, red bell.
2. Every inactive tab carried its own grey number cell — heavy.
3. Session "0" beside tab 0 read as "0 0".
4. Shell tabs all read "fenrir": a plain shell leaves =pane_title= at the
   hostname (=#{host_short}= = =fenrir=).
5. Optional: the 20-cell "…" cut looked clipped.

** What changed

- =tmux.conf=: the two window-text lines became a marked block
  (=# >>> palette= … =# <<< palette=) owned by =try-palette.sh=. Every
  option inside is set explicitly in every variant, because catppuccin fills
  =@catppuccin_status_<module>_icon_bg/_fg= with =set -o= and a dropped line
  would leave the previous variant's colour live.
- =claude.conf=: status-left is wrapped in
  =#{?#{&&:#{@bar_hide_numeric_session},#{m/r:^[0-9]+$,#{session_name}}},,…}=.
  The flag is 0 except in =neutral-info= / =neutral-short=. Side effect when
  hidden: the prefix-armed session icon is hidden too.
- =try-palette.sh= variants:
  | variant       | fixes   | what it sets                                                                 |
  |---------------+---------+------------------------------------------------------------------------------|
  | original      | —       | round-three values, for comparison and rollback                              |
  | neutral       | 1, 2    | module icon cells surface2 =#585b70= with fg =#cdd6f4= (4.62:1); session icon mauve =#cba6f7= only while prefix is armed; inactive tabs drop the number cell, index moves into the title cell in overlay2 =#9399b2= (4.45:1) |
  | neutral-info  | 1-4     | neutral + numeric session hidden + a tab whose title is the hostname shows the cwd basename, =~= at =$HOME= |
  | neutral-short | 1-5     | neutral-info + titles cut at 14 cells, no ellipsis                           |
  Red =#f38ba8= remains only on the fleet bell block and gitmux state/conflict.
- No new glyphs, no change to shapes, =█= separators, state glyphs, roster
  logic, cc-beacon or =~/.gitmux.conf=.

* Round six: one block (2026-10-23)

User verdict on =neutral-bright=: still too dark, then 「應該大刀闊斧 使用現代的
配色風格來設計bar」. Offered three directions (AskUserQuestion): 一塊規則,
透明底線, 亮色塊. Picked **一塊規則** — the current tab is the only filled block
on the bar; everything else is text, and hierarchy comes from brightness, not
from the count of coloured cells. Rounds 1–5 only re-tinted catppuccin's
block-per-module layout; this round stops using its composed strings.

** Where the formats live

catppuccin stays loaded for its palette and for the older A/B variants, but
no longer owns the formats. Anything above =run tpm= loses to its
unconditional =set -gF window-status-*=, so the one-block formats are written
AFTER the theme into =claude.conf=, between =# >>> bar-format= /
=# <<< bar-format=, by =try-palette.sh oneblock=. Every other variant writes
an empty block there (plus =set -gu window-status-separator=), and the
catppuccin composition lines above the markers stand again.

- =cc-beacon install-bar=: publishes =@claude_tab_glyph_mono= beside
  =@claude_tab_glyph= — same conditional, no =#[fg=]=, so the glyph inherits
  the mauve block's crust foreground (red or yellow on mauve was unreadable).
  The roster is now text: =#{?blocked,#[fg=#f38ba8]#[bold] N ,}#[default]=;
  the =█= cells and =@catppuccin_status_module_text_bg= are gone. Tests:
  mono twin balanced, same glyph order, contains no =#[=; roster contains no
  =█= and no =#[bg=]=.
