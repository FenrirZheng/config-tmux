- [2026-08-09 Sun] — **=capture-pane -J= joins only inside the requested range**, and the

  line exactly =pane_width= wide.

- [2026-08-09 Sun] — **Copy-mode search cannot be driven programmatically. Confirmed six

  future session tempted to automate the search half should read this note first.

- [2026-08-09 Sun] — **tmux-in-tmux is the technique that unlocks all of this.** Six rigs
  failed because =send-keys -t <pane>= delivers to the pane's *process* and bypasses tmux's
  key table — so it can neither fire a binding nor type into a prompt. Run the inner
  server's client **inside a pane of an outer server** and the inner client's tty becomes an
  ordinary pane: =send-keys= on the outer server then feeds it real keystrokes (prefix,
  prompt text, Enter), and =capture-pane= on the outer pane reads back whatever the inner
  client renders, status line included. That single trick closed T3 and the whole live half
  of T14. If a future session concludes "copy-mode search cannot be automated", it has
  stopped one step early.
